نظام حافز المتمة — مشروع نسخة ويندوز
====================================

هذا مجلد مشروع التحويل لبرنامج سطح مكتب، ويحتوي على ملف HTML الأصلي الذي رفعه المستخدم دون تغيير محتواه، مع غلاف Electron.

الأهداف المطلوبة:
1) Windows 8 بنظام 32-bit: بناء ia32 باستخدام Electron 22.3.27 (يلزم اختبار النسخة على الجهاز الحقيقي قبل اعتمادها).
2) Windows 10 بنظام 32-bit: بناء ia32.
3) Windows 10 بنظام 64-bit: بناء x64.

طريقة البناء على جهاز Windows أو Linux لديه Node.js وnpm واتصال إنترنت:
1. افتح الطرفية داخل هذا المجلد.
2. نفّذ: npm install
3. لو أردت نسخة 32-bit: npm run build:win32
4. لو أردت نسخة 64-bit: npm run build:win64
5. ملفات التثبيت ستظهر في مجلد dist.

تنبيه مهم:
- هذه ملفات المشروع وإعدادات البناء وليست ملفات EXE نهائية تم اختبارها على Windows.
- Windows 8 قد يحتاج اختبارًا عمليًا للتوافق، ولا يمكن ضمانه من إعداد المشروع وحده.
- لم تُضف حماية ربط الجهاز أو مفتاح تفعيل بعد؛ يلزم تصميمها واختبارها كخطوة منفصلة. التفعيل دون إنترنت ممكن بتوقيع ترخيص، لكنه لا يمنع النسخ منعًا مطلقًا.
- حافظ على نسخ احتياطية من بيانات النظام قبل أي تجربة.
